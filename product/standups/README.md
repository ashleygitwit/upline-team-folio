# Product standups

Twice-weekly (Tue and Thu mornings).

**Core:** Ashley (PM for these meetings), Doug (eng), Amanda (design).
**Optional:** Davy (sales), JV (CEO).

**The board everyone can see:** [`board.md`](board.md). That is the file to open in Claude, GitHub, or the repo. Ashley also keeps a Cursor canvas of the same board; the canvas does not travel outside Cursor.

## How this works

1. Drop the transcript in chat (Ashley, in Cursor).
2. It gets filed here as `YYYY-MM-DD-product-standup.md`.
3. [`board.md`](board.md) gets updated: open to-dos, what shipped, blockers, parking lot.

Do not put sales-demo transcripts here. Those live in [`../../go-to-market/sales-demos/`](../../go-to-market/sales-demos/). Pilot session notes stay in upline-poc.

## If you are in Claude

Point Claude at Team Folio (Claude Code on this repo, or a Claude Project with this folder attached). Then:

> What’s open from product standup?

Claude should read [`board.md`](board.md). To go back to a specific meeting, open the dated transcript in this folder.
