# Above the line / below the line — topics to cover

1. **Mobile** — Desktop only, some surfaces, or all? At what fidelity?
2. **Who the product is for** — Working users only, or a separate owner/buyer surface too?
3. **Permissions / visibility** — Everyone sees the full book, or only “my” items? One shared layout, or different views by role?
4. **Roles & seats** — One admin + basic users (unlimited)? What can admin do that others can’t?
5. **Where work happens** — In-app, email, VA toolkit, SMS, phone/recording — which are above the line, and at what fidelity?

7. **Email customization** — Locked default, choose/write their own, or edit every send? Onboarding-only or always editable?
8. **Threshold customization** — Locked, set at onboarding, or always editable? Which thresholds?
9. **Brand / white-label** — Questionnaire only, plus policyholder proposal, or more? Logo only vs fuller brand?
10. **Lines of business** — Reach all home/auto households; shop home/auto only — any exceptions?
11. **Delight / celebration** — Any animation or delight pass above the line?
12. **Customization overall** — For anything the agency can change: locked, onboarding-only, or ongoing self-serve — and above or below if we can’t finish it?
