# Project planning

When we do the work, in what order, and in which rooms.

This is **not** product strategy. If the question is "what do we believe / what do we build / how do we price it," that lives in [`../product/`](../product/). If the question is "when is sprint week, what did How Should We decide," it lives here.

## What is here

| File | What it is |
|------|------------|
| [`how-to-run-how-should-we.md`](how-to-run-how-should-we.md) | How to run the weekly Monday meeting. Cursor skill: say **How Should We this week**. |
| [`2026-08-24-how-should-we.md`](2026-08-24-how-should-we.md) | First captured session — go hard and fast, four lanes |
| [`2026-09-08-strategy-sprint.md`](2026-09-08-strategy-sprint.md) | Sprint week plan (Tue–Fri in the room) |
| [`2026-09-08-sprint-week-notion.md`](2026-09-08-sprint-week-notion.md) | Same week, Notion-paste version |
| [`2026-09-08-sprint-prep.md`](2026-09-08-sprint-prep.md) | This week’s prep: emails, print pack, how we present and capture |
| [`execution-plan.md`](execution-plan.md) | Generated living plan from `data/venture-plan.json` |

New How Should We notes go here as `YYYY-MM-DD-how-should-we.md`.

## What does *not* belong here

- Pricing, journey maps, VA/shopping, MVP line → [`../product/`](../product/)
- Sales decks and prospect notes → [`../go-to-market/`](../go-to-market/)
- Through Line pages → [`../internal-comms/`](../internal-comms/)
