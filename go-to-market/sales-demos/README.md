# Sales demos

Prospect / waitlist demo call artifacts — transcripts, notes, and follow-ups.

**Not** pilot design-customer sessions. Those live in upline-poc under agency pilot folders.

## Layout

```
sales-demos/
  YYYY-MM-DD-{prospect-or-company}/
    transcript.md
    insights.md       # living: likes, agency, why they reached out, trends, red flags
    notes.md          # optional
```

## Association rule

- Raw capture stays here under `go-to-market/sales-demos/`
- Promote useful signal upward only with an explicit **sales demo** source tag
