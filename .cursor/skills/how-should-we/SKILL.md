# How Should We

Weekly Monday strategy meeting. Not a standup. Not a customer check-in.

Read `project-planning/how-to-run-how-should-we.md` (Team Folio repo root) before drafting. Follow that guide. Do not invent a new format.

## When she says "run How Should We" / "How Should We this week"

1. Confirm the meeting date (usually next Monday).
2. Load, in order:
   - The how-to guide above
   - The latest `project-planning/YYYY-MM-DD-how-should-we.md`
   - `project-planning/execution-plan.md`
   - Anything she pastes (notes, transcript, funnel counts)
3. Draft a **paste-ready agenda** using the four lanes and the template in the how-to guide.
4. Offer to save the agenda, then after the meeting write `project-planning/YYYY-MM-DD-how-should-we.md`.

## Hard rules

- Every main item is a **How should we…** decision, not a status update.
- Status and funnel numbers go under **Last week's learnings**.
- Do not repeat closed learnings (e.g. one-email outreach).
- Do not use the Members 1st / Stockton Hill customer-session format.
- Do not invent weekly reality. If a lane is quiet, say so and keep it short.

## After the meeting

If she drops a transcript or recap, write a session note with:

- Headline
- Decisions / direction (by lane)
- Open / confirm by mid-week (owner table)
- What changes next week's agenda
